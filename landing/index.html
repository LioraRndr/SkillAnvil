Workflow

从散落目录到可维护资产

SkillAnvil 面向已经在多种 Coding Agent 之间切换的人。它不替你发明新的规范， 而是把现有目录读进来，让同步、版本和来源变得可见。

01

扫描

识别本地 Agent 的 Skill 文件夹，自动聚合同名 Skill 和同源合集。

02

整理

用收藏、标签和子分类维护你的工作方式，不改变原始目录结构。

03

编辑

打开 SKILL.md 或相关文件，保留原编码写回，并在保存时生成快照。

04

同步

对比目标 Agent 的内容状态，只把需要更新的 Skill 同步过去。

Capabilities

为 Skill 维护做的具体功能

统一管理

在一个窗口里查看多个 Agent 的 Skill，避免在不同隐藏目录之间来回翻找。

编码感知

读取并写回 UTF-8、UTF-8 BOM、GBK 文件，降低中文 Skill 被转码破坏的风险。

跨 Agent 同步

用内容哈希判断相同、不同或缺失，只显示真正需要处理的目标。

快照历史

保存时记录版本，后续可以查看差异或一键回滚到旧快照。

来源溯源

对照公共 Skill 注册表和上游 SKILL.md，标记已验证、疑似、本地或歧义来源。

自带翻译接口

使用你自己的 OpenAI 兼容或 Anthropic 原生接口，只在触发翻译时发送内容。

Privacy

本地优先，不把你的 Skill 内容默认上传

应用只在检查更新、用户主动溯源或用户主动翻译时联网。溯源发送的是 Skill 名称， 翻译使用你配置的接口和密钥。设置保存在本机应用数据目录。
